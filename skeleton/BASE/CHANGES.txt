# MinUI+ v1.3.2 — changes since launch

For the Miyoo A30. This ZIP is a complete release, suitable for manual download from a mirror.

Manual update: back up your card first. Extract the outer download ZIP and merge its contents into the SD card root,
replacing bundled application/tool files when asked. Keep MinUI.zip zipped; the A30 installs it on the next power-on.
Copy the included Tools and Emus folders too so their fixes are installed. Preserve any personally customized artwork
or bezels from your backup. The updater's Shut Down prompt requires you to turn the A30 back on manually.

From v1.1 the built-in updater checks GitLab. Devices on v1.07 or older look for updates on GitHub, where every release is published too.

This is a consolidated comparison with v1.0.0, rather than a list of every intermediate hotfix. This v1.3.2 package includes all changes below. The newest changes come first, then v1.0.1–v1.0.5, then v1.06.

## New in v1.3.2

### Sleep and power

- Waking is faster: under a tenth of a second, in the menu or in a game.
- After a minute asleep, the A30 goes into a real low-power suspend, and wakes from it with the Power button as usual.
- Wi-Fi switches off on a long sleep and comes back on waking. While Wi-Fi is off, the Wi-Fi chip is now fully powered down; while it's on, it dozes between packets.
- Wi-Fi joins whichever saved network is in range by itself, and starts again on its own if it couldn't after a sleep.
- The clock isn't re-synced on every reconnect, only when its last sync is more than 6 hours old.
- The menu, the pause menu and paused games now rest between button presses instead of drawing 60 empty frames a second.
- The background music, the thumbstick and the volume buttons now wake the CPU far less often.
- The A30's unused USB file transfer (MTP) and USB debugging (adb) services are stopped at boot. Charging over USB works as before.
- Games start sooner: the A30's two spare CPU cores are switched off in the background instead of while you wait.

### Play Time

- A new list: the top 20 games, four at a time, each with its rank, box art, total time, average session and number of sessions. The selection boxes the whole game, and long names scroll.
- Your total time across everything, in hours and minutes, is in the bottom bar.
- It moves a line at a time like every other list. The carousel view is gone from Play Time.

### The home button

- In a list of games (or the carousel), a tap of MENU, the button with the house, opens that game's options: core, CPU speed, box art, rename and delete. This replaces MENU + Y.
- Everywhere else a tap still opens Settings, and the system list shows a house button hint for it.
- The Controls page shows the house button.

### Polish

- Settings, Tools, Play Time, the core picker and the game options all have a grey heading on the clock's line, with full-width rows below. A line about the highlighted row is shown at the bottom.
- Scrolling text moves smoothly at 60 frames a second everywhere, achievements included.
- Lists of games show X RESUME (or X OPEN with A and X swapped) instead of the power and sleep hint.
- In the game switcher, a DS game whose save state is missing says so under its picture, the same way PICO-8 games do.

### Fixes

- DS saves and save states left in DraStic's old folder in .system are copied once to the new one. Nothing is overwritten, and a save state is skipped if the game has a newer in-game save.
- The clock no longer sits over the heading of the game options opened from the carousel.
- The thumbstick's calibration is only written to the card when it changes, not on every app quit.
- Holding a direction no longer skips ahead on its first repeat.
- Play time and the game switcher list are written on their own, without flushing the whole card mid-game.

## New in v1.3.1

### Updates

- A slow or patchy Wi-Fi connection has longer to download an update: 30 minutes instead of 10, with the progress screen staying up until it's done. (This helps from the next update on: updating to v1.3.1 itself still uses your current updater.)
- The update screen now says "Updating MinUI+".
- Devices on v1.07 or older find updates on GitHub again.

### Sleep and power

- Waking from sleep is quicker: the A30 now notices the power button the moment it's let go, instead of checking five times a second.
- Sleep uses less battery: nothing runs between button presses, the battery is checked every 30 seconds instead of every 5, and the volume and brightness buttons are watched without waking 60 times a second.
- Waking no longer writes the same brightness and volume back to the card, and changing them no longer flushes the whole card each step.
- A short press of Power turns the A30 on: MinUI+ sets the A30's power chip to a short hold, from the next power-on. (A battery that runs flat resets it until the next boot.)

### Polish

- RetroAchievements: the list shows five achievements at a time, with the highlighted one's description on a single line that scrolls when it's long.
- Long game names wrap onto more lines instead of running off the screen, in the delete prompts and on every message screen; short notices are shortened to fit.
- The game switcher opens faster after a game with RetroAchievements: quitting waits only for unlocks still being sent, not for the regular check-ins.
- The on-screen keyboard clicks as you type and move, and B deletes a letter (or goes back when there's nothing typed).
- PICO-8 runs at the normal CPU speed instead of the highest, which the A30 can't hold for long.

### Fixes

- Fixes for crashes and freezes in rare cases: a font or image that fails to load, the device running low on memory, a song that won't play (the music no longer gets stuck), and very long folder or file names in Sync Achievements and Box Art.
- RetroAchievements is steadier when several requests run at once, and an unlock earned offline can no longer be lost when two are saved at the same moment.
- Saved Wi-Fi networks, the RetroAchievements sign-in and the DraStic and PICO-8 settings are written safely, so a power cut or a full card can't leave them empty or half-written.
- A damaged settings file can no longer leave the screen dark or the volume past its top.
- Renaming, removing and editing game lists no longer stops at a fixed size, and the crash log is kept from growing without end.

## New in v1.3

### Rewind

- Hold a button to rewind a game, frame by frame. Pick the button in the pause menu, Options > Shortcuts > Hold Rewind: any button, or MENU plus a button. It does nothing (and costs nothing) until you pick one.
- The game goes back silently while you hold it, and plays on from there when you let go. Loading a save state or resetting the game starts the rewind history over.
- Rewind is off in RetroAchievements hardcore, for the Nintendo 64, and for systems whose save states are too big to rewind smoothly.

### Boot Tweaks (optional)

A new tool in Tools that tweaks the A30's own bootloader, in its internal memory:

- Increases boot speed.
- Shortens how long you have to hold Power to turn on the A30.
- Adds a tactile vibration when powering on.

It only runs when you open it, and asks first. Update the A30 to Miyoo's firmware 20240713 first (lomiyoo.com/pages/firmware): Boot Tweaks changes nothing on any other. The README's Boot Tweaks section has the steps, and how to remove the tool if you don't want it. The original pieces are saved to the card first, and Undo in the same tool puts them back. The changes stay if you boot into a different launcher. Don't turn the A30 off while it writes.

### Faster startup

- The menu comes up sooner after power-on. The systems and games are read while the screen starts, and Wi-Fi, the clock check and other housekeeping wait until the menu is on screen.
- The libraries the menu needs are copied once from your A30's firmware to the card, which reads them faster. The copy is only used while it still matches the firmware.
- Volume and CPU settings are applied directly instead of through extra programs, and a fresh boot no longer checks every system folder for multi-disc games again.
- Each boot's timings are saved in logs/boot.txt.

### Other changes

- Holding Power to turn off gives a short vibration, so you can feel it.
- Settings: "Sleep Light" is now called "Sleep LED".

## New in v1.2.2

A polish release for v1.2.

### Getting around

- In a system's games, Up / Down in the carousel and Left / Right in the list go to the previous or next system. The system's name pops up as you switch.
- The Borders folder is now called Bezels, and the menus say "Screen Bezel". The update moves your Borders folder over by itself, keeping any bezels you added or changed.

### Menus

- Settings: the rows are brighter, so they stand out from the heading, and a description too long for the bottom of the screen scrolls instead of being cut off.
- Settings shows the right MinUI+ version (it said v1.1).
- In Settings, A now changes Clock, Theme, Time Zone and the power timers too, like the rows that already worked that way.
- PICO-8's pause menu can pin the game to the game switcher with X, like every other system.
- Menu names are Title Case everywhere, the RetroAchievements sign in and sign out questions name their button, and deleting a game says exactly what goes with it (box art, bezel or both).
- In the in-game menu, A on Load with an empty slot no longer closes the menu, and changing discs clicks like changing slots.

### Fixes

- Very long game or folder names could overrun file paths in the launcher and the in-game menu.
- A multi-disc playlist with more than 9 discs could crash the game when its menu opened. The menu now offers the first 9.

## New in v1.2.1

A hotfix for v1.2.

- The volume and brightness bar no longer comes up faint after it has faded out once.
- RetroAchievements: a game no longer says "Invalid JSON" offline. A dropped connection could save half of a game's achievement list, which then failed to load whenever the A30 was offline. Cut-off replies are now thrown away, and a broken saved list is ignored and refreshed the next time you're online.
- Offline, a game whose achievements were never downloaded now says so, instead of "No response".

## New in v1.2

### PICO-8, the official one (bring your own)

- If you have bought PICO-8, play carts with it, Splore included, in the new "Pico-8 Native (PICO8)" folder. PICO-8 is not included: README.txt says how to add it.
- It plays like every other system: MENU opens the in-game menu with play time, and Options has Screen Scaling, Screen Effect, Screen Bezel and Button Layout. START is PICO-8's own pause menu, and the power button sleeps.
- The same settings are in MENU + Y on its carts and on Splore. Fullscreen with the LCD grid is the default.
- Hold MENU for the game switcher. PICO-8 has no save states, so the switcher keeps a picture and starts the cart over, and says so under the picture.
- One "Pico-8 (P8)" cart can switch to the official PICO-8 in MENU + Y.
- Splore has its own box art and shows up as "Splore".

### Game switcher and resume

- Fixed a freeze when opening the game switcher in some games, such as Advance Wars on the GBA.
- Resume (X) picks up from the newer of the switcher's quick save and your last save.

### Box Art

- Much faster on a big card: opening it no longer reads every piece of art, and MISSING ONLY skips games the library had no match for in the last 14 days (REPLACE still tries them).
- Art it saves is smaller, and resizing also shrinks older art that had transparency.
- Fixed the game lists scrolling slowly after using Box Art.
- After finding art, SEE LIST shows the games that still have none and why (no match, system not in the library, couldn't download).

### RetroAchievements

- A long achievement description now shows in full.
- The achievements list's heading no longer runs into the clock.
- Syncing is faster, especially later runs: games already identified aren't read again.
- After a sync, SEE LIST shows the games without achievements and why (not in RetroAchievements, no achievements yet, couldn't identify, couldn't check).

### Volume and brightness

- Changing the volume or brightness during a game now shows the bar over it, on every system (PICO-8 and Splore, fake-08 and the DS too), and each step clicks, as in the menus.
- The bar also shows in the confirmations and pickers that didn't have it (deleting a game, choosing a core, the game menu, Set Time, messages in the in-game menu).
- PICO-8's in-game menu now clicks when you move, choose and go back, like every other system's.

### Menus

- A title too long for the top of a menu (Options, the on-screen keyboard) scrolls instead of being cut off.
- The pause menu's save picture loads once per slot, so moving through it is snappier.
- Smaller system art files.

## New in v1.1

### New systems

- Added **Nintendo DS**, through DraStic with MinUI+'s own in-game menu: save states, screen layouts, bezels, Thumbstick and CPU Speed settings, and RetroAchievements (softcore). DraStic isn't included: the README says where to get it.

### Nintendo 64

- **Nintendo 64 stays experimental, and your mileage may vary.** Results depend heavily on the game. Speed and graphics improved in this version, but expect glitches and slowdowns, and some games won't be playable.
- Mario Tennis: improved the effects around the ball and the screen after a replay. Some shimmering and odd textures remain in replays.

### Clock and settings

- The clock now stays right while the A30 is off, and shows only once it's been synced over Wi-Fi or set by hand. It may stay hidden after this update until you do one of those.
- A new **Set Time** in Settings sets the clock without Wi-Fi.

### Menus and saves

- A game name too long for the in-game menu now scrolls instead of being cut off.
- A save state is written beside the old one first, so losing power mid-save no longer destroys the previous state.
- RetroAchievements logs why it couldn't connect, and no longer lists the server's notice about unrecognized emulators.

### Updates

- The built-in updater now checks GitLab.

## New in v1.07

### New systems

- Added Capcom Play System 1, 2 and 3, Final Burn Neo, MAME 2003+, Neo Geo, Sega CD and Sega 32X, each with its own system art. Arcade systems also get vertical-game bezels where they apply. BIOS files are not included; README.txt says which each system needs and where it goes (Neo Geo's goes beside the games).
- Added Nintendo 64 as an **experimental** system. Expect graphics glitches and uneven speed: Banjo-Kazooie and Mario Tennis are known to show visual problems, and many games won't run at full speed.

### Rumble

- One **Rumble Strength** option (Off, 1–10) now covers Game Boy, Game Boy Color, Game Boy Advance on gpSP and mGBA, PlayStation and Pokémon mini, so a number feels the same everywhere. It can also be set per game from the game menu (MENU + Y). Values set in the old per-core options are not carried over.
- Fixed Pokémon Pinball: Ruby & Sapphire on gpSP vibrating constantly from startup, having its Rumble option greyed out, and vibrating on after leaving Options during the test buzz.

### Menus and controls

- A new **Swap A and X** setting makes A resume and X open in game lists.
- The game menu (MENU + Y) now has a CPU speed row and scrolls when it has more rows than fit.
- Wi-Fi, Box Art, Controls and RetroAchievements open instantly, built into MinUI+ itself.
- A lightning bolt now appears over the battery icon while a charger is connected, with the battery level still visible.
- Tools you add to the Tools folder are no longer moved away at startup. If this removed one of yours, restore it from .minui/removed-official-tools.

### Wi-Fi

- Several Wi-Fi networks can be saved, and MinUI+ joins whichever is in range.
- A wrong password no longer looks like a successful connection, and clock sync no longer hangs when a time server doesn't answer.

### Stability

- AUTO CPU speed is capped at 1344 MHz on all cores.

## Released since v1.0.0

### Updates directly on the A30

- MinUI+ quietly checks GitHub for updates after Wi-Fi connects. An **Update Available!** category, with matching system artwork, appears above the systems only when a newer build is available.
- Read scrollable patch notes on the device before confirming a download.
- Update checks handle saved networks, hotspots that appear after startup, and reconnections. Temporary connection failures are retried; successful checks are throttled to avoid unnecessary requests.
- Downloads use verified HTTPS, SHA-256 checks and ZIP validation. The updater checks available card space and compares build dates and numbers to avoid offering older builds.
- A progress bar covers download, verification and unpacking. The completion prompt no longer gets stuck behind the full progress bar.
- When ready, choose **Shut Down**, then manually turn the A30 back on to finish installation. **Later** lets you return to MinUI+ and finish on a subsequent power-on.
- Updates preserve games, saves, settings and existing custom system art, bezels, music and BIOS files while updating the application and bundled tools.
- A subtle **MinUI+ version** row is available at the bottom of Settings.

### Automatic clock and connection settings

- The manual clock has been replaced with automatic time synchronization over Wi-Fi, with 12-hour, 24-hour and Off options.
- After a full power-off, the clock stays hidden until Wi-Fi synchronizes it during that boot. The A30 does not keep accurate time while powered off; it does continue keeping time during sleep. Once synchronized, the clock can remain visible after disconnecting Wi-Fi.
- Added automatic time-zone lookup and manual time-zone selection, including daylight-saving rules where applicable. Fixed left/right navigation through the zone list.
- Wi-Fi setup now lives in Settings, with connection status shown there, rather than appearing as a separate visible tool.

### Gentler vibration and sleep controls

- Reworked A30 rumble to provide gentler, variable-strength feedback instead of effectively continuous full-power vibration.
- Corrected how strong and weak rumble channels are combined, particularly relevant to PlayStation games. Reduced the default rumble level for Game Boy/Game Boy Color and Pokémon Mini.
- Holding MENU gives a short, gentle vibration when the game-switcher hold threshold is reached.
- Added a **Sleep Light** On/Off setting, with a preview while selecting it.

### More consistent tools, sound and presentation

- Moved the existing play-time ranking into **Tools → Play Time**, showing total play time when it opens. **MENU + X** clears tracked play time after confirmation; the old data is backed up.
- Added consistent navigation sounds and background music across the tools, including Wi-Fi, Box Art, Controls and RetroAchievements.
- Music resumes where it left off when moving between the launcher and tools, with a shorter fade when resuming.
- Improved Controls page headings and shortcut explanations, and adjusted the RetroAchievements tool layout.
- Lightened CRT scanlines so the picture is less dark.
- Removed the unsupported RetroAchievements hardcore option and associated UI. Achievement unlocks use softcore; existing offline achievement support remains available.

### Cleaner installation and folder layout

- Fresh installs use one descriptive ROM folder per supported system, such as **Game Boy Advance (GBA)**.
- Empty legacy aliases are cleaned up without removing folders containing games. Removed the duplicate Supafaust system folder and artwork; Supafaust remains an alternate Super Nintendo core.
- Removed unwanted inherited tools: Bootlogo, manual Clock, Files, Input, Remove Loading and Reset Stick. Existing copies are moved into a hidden backup rather than permanently deleted. The visible Tools menu focuses on Play Time, RetroAchievements, Box Art and Controls.
- Updated setup instructions and documentation to match the new clock, updater, folders and tool layout.

## New in v1.06

- Moved Box Art's menu options below the Wi-Fi/time/battery area and gave the first option the full available row width.
- Battery indication uses the device's reported percentage rather than rounding upward in large 20% steps. This improves display granularity; it is not a new battery calibration.
- Volume and brightness changes play the existing menu navigation click, respecting the menu-sound preference and mute.
- Holding MENU alone no longer opens the brightness popup; press MENU with − or + to display and adjust brightness.
- Added a bounded escape from a full audio buffer when the output stops draining, allowing control processing to resume instead of retrying indefinitely. Audio underruns now fill with silence instead of reversed leftover samples.
- Corrected update-check throttling after a backward clock correction and made failed-unpacking messages acknowledge that some files may already have been copied.

Features already present at launch—such as the box-art carousel, game switcher, per-game core selection, themes, automatic CPU speed, play-time tracking, bezels and offline achievements—are deliberately not counted again as new additions.
